# SVG asset preview checklist

| SVG | Inspection criteria |
|---|---|
| lighthouse-main.svg | Tower/lantern silhouette, proportions, legibility at wide scale |
| robot-main.svg | Recognizable small robot, balanced head/body/limbs, amber visor |
| beacon-mechanism.svg | Gear and coupling geometry, concentric alignment, contrast |
| lighthouse-lens.svg | Fresnel facets, central lamp and edge highlights |
| storm-sea.svg | Readable horizon, waves/rock separation and restrained lightning |
| lighthouse-door.svg | Arched doorway, rivets and material contrast |
| spiral-stair.svg | Central void, concentric stair ring and direction clarity |
| robot-hands.svg | Clear pincers and pin alignment with negative space |
| beacon-beam.svg | Soft transparent gradient and clear directional shape |
| distant-vessel.svg | Legible small boat silhouette at final wide distance |

All SVG files are rendered individually and visually checked before animation. The previews are design references: the final 2D Remotion composition recreates the selected visual grammar as animated inline SVG groups and paths rather than importing these files as static image layers.
